# VOID — Premium Streetwear Website

A dark-mode, Gen-Z premium streetwear storefront built with plain HTML, CSS and JavaScript.

## Run in VS Code

1. Extract this ZIP.
2. Open the `VOID_streetwear` folder in VS Code.
3. Open `index.html`.
4. Easiest option: install the **Live Server** VS Code extension, then right-click `index.html` and choose **Open with Live Server**.
5. Or simply double-click `index.html` to open it in your browser.

## Included

- Responsive dark-mode storefront
- Hero / Drop 001 section
- Product filtering
- Product quick-view modal
- Size selection
- Add-to-bag cart
- Persistent cart using localStorage
- Wishlist
- Search
- Newsletter interaction
- Mobile responsive layout
- Gen-Z microcopy
- Philippine peso pricing

## Important

The checkout is a front-end demo. To accept real money/orders you will need to connect a real e-commerce backend/payment provider.

You can change products and prices in `js/script.js`.
You can change the visual design in `css/style.css`.
